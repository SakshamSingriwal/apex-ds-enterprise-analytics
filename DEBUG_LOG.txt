# Bug Fixes Log - Session June 7, 2026

## 1. Invalid AutoGluon kwargs fix in core/goal_agent.py
- **Error description**: TypeError when calling TabularPredictor.fit() with invalid keyword arguments
- **Root cause**: Using deprecated/presets parameter and invalid keyword arguments (calibrate_pred_proba) that are not accepted by AutoGluon 1.5.0+
- **Fix applied**: Removed invalid kwargs, restructured fit() call to use positional arguments and valid parameters (holdout_frac, auto_stack, calibrate)
- **File changed**: core/goal_agent.py
- **Lines changed**: 36-51

## 2. Streamlit use_container_width deprecation fixes (7 occurrences)
- **Error description**: st.plotly_chart() calls using deprecated use_container_width parameter
- **Root cause**: Streamlit 1.35.0 deprecated use_container_width in favor of width="stretch"
- **Fix applied**: Changed use_container_width=True to width="stretch" in all 7 occurrences
- **File changed**: app.py
- **Lines changed**: 385, 428, 444, 458, 521, 610, 646

## 3. pd.to_datetime risky call fix
- **Error description**: datetime detection crashing on invalid date strings with errors='raise'
- **Root cause**: pd.to_datetime() was called with errors='raise' which throws exception on unparseable dates
- **Fix applied**: Changed to errors='coerce' and added check for converted.isna().all() to validate datetime columns
- **File changed**: app.py
- **Lines changed**: 307-310
